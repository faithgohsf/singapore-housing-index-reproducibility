# Technical location ledger dictionary

One row per originally flagged case. Case ID links to the unchanged five-column response form; building_id is the frozen reconstructed HDB key. Housing classification records the completed human assessment separately from location_resolution_status. selected_postal_code is a six-digit text identifier. selected_onemap_building/address, latitude/longitude (WGS84 decimal degrees) and x_svy21/y_svy21 (metres) are the retained provider address point, not a surveyed building centroid or verified panorama. maximum_candidate_separation_m is maximum Euclidean SVY21 distance from the selected point to returned candidates; it is descriptive and is not an automatic match threshold. decision_reason states case-specific reasoning. corroborating_source_url/facts identify independently checked supporting records, not the reviewer’s case-specific browsing history. frozen_hdb_evidence identifies the frozen official source row. onemap_snapshot/sha256 identify exact payload evidence; onemap_response_warning preserves the missing-token message without asserting authenticated success. assessment_date is the technical assessment date, not the human observation date. frozen_analysis_coordinates_changed and historical_score_conflicts_changed are False: no retrospective analytical replacement. remaining_manual_information_required is empty where the technical case is resolved.
